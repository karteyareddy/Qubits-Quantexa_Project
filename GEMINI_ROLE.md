# Gemini Review Role

Gemini is the second engineering reviewer.

Do not let Gemini become a second uncontrolled implementation agent.

Review:
- architecture
- QUBO correctness
- QAOA implementation
- emergency logic
- simulation consistency
- baseline fairness
- WebSocket state handling
- frontend UX
- security
- test coverage

For each issue:
- file
- location
- issue
- evidence
- correction
- severity

Do not make claims not supported by the repository.
