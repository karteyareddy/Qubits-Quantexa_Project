# Development Skills

## Repository archaeology
Understand existing code before modifying it.

## Migration
Move logic without changing behavior unnecessarily.

## API design
Define typed request/response contracts before frontend integration.

## Quantum engineering
Understand QUBO -> Ising -> QAOA -> measurement -> decode -> feasibility -> classical evaluation.

## Simulation engineering
Make all experiments deterministic when seed is fixed.

## Frontend engineering
Use reusable typed components and WebSocket state rather than polling for every tick.

## Debugging
Reproduce -> isolate -> fix root cause -> regression test -> full relevant suite.

## Experiment integrity
Baseline and hybrid comparisons must use identical scenario inputs.
